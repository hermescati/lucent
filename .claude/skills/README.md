# Project skills

`animation-performance`, `review-animations`, `choreograph` and `apple-design` come from
[emilkowalski/skills](https://github.com/emilkowalski/skills) (commit c8a7962, MIT, see
`LICENSE-emilkowalski-skills`). Each has a short "In Lucent" note under its frontmatter: measured iOS behaviour
overrides the skills' default timings and budgets. Keep that note when updating them from upstream.

`build-component` is Lucent's own: the per-component workflow, from API and anatomy through measuring iOS, glass,
motion, fallback, review and docs.
